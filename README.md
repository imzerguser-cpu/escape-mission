# 미션 방탈출 (협동 미션형)

[escape](https://github.com/imzerguser-cpu/escape) 방탈출 플랫폼을 바탕으로, 문제 풀이 대신 **6개 교실의 협동 미션**을 해결하는 버전입니다.

| 교실 | 미션 |
|---|---|
| 1학년 교실 | 2인 1조 3-6-3 더블 스택스 1분 안에 성공 (연습 영상 포함) |
| VR실 | 단체 줄넘기 20개 (걸린 것 포함) |
| 도서관 | 귀신 이야기 책 또는 그림책 3권 찾아 인증샷 |
| 컴퓨터실 | 굴러가는 훌라후프 통과하기 (서로 다른 3명) |
| 영어체험실 | 숟가락으로 탁구공 떨어뜨리지 않고 옮기기 |
| 과학실 | 컵 12개에 탁구공 5개 넣기 |

- 조장 태블릿: 교실별 🟢 비어 있음 / 🔴 사용 중 / ✅ 성공 실시간 표시, "미션 시작"으로 교실 사용
- 교실 선생님: `?teacher=M1`~`M6` 주소 → 관리자 비밀번호 → "미션 성공" 버튼 (누르면 교실이 즉시 비워짐)
- 6개 미션을 모두 성공하면 방탈출 완료
- 데이터는 Firebase `escape_data/mission_app` 아래에 저장 (기존 escape 데이터와 분리)
